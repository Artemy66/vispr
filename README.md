Веб-приложение с CI/CD и мониторингом

Простое веб-приложение (визитка) на Flask с редактированием через админку,
формой заявок, health-check и метриками Prometheus. Разворачивается в Docker,
собирается в CI/CD (GitHub Actions), деплоится на VPS (Yandex Cloud),
мониторится через Prometheus + Grafana + cAdvisor.
